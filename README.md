# 🌊 IoT Tank Monitoring System

A web-based IoT dashboard that monitors water tank levels using an ESP8266, Ultrasonic Sensor, and ThingSpeak. The dashboard displays real-time water level data with a modern and responsive interface.

## 🚀 Live Demo

https://sauddaniyal.github.io/tank-monitoring-system/

## 📌 Features

- Real-time water level monitoring
- ThingSpeak API integration
- Interactive water tank visualization
- Automatic data refresh
- Responsive dashboard design
- Water level history display
